The website presents my research interests, selected publications, professional experience, education, awards, and contact information.

Visit the website at **[watterworth.github.io](https://watterworth.github.io)**.

The site is built as a lightweight, self-contained HTML page and hosted using GitHub Pages. The complete website is contained in [`index.html`](index.html).
